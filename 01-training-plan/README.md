# Challenge 1 – Training plan

Session skeleton: **Topic (What?)**, **Duration (How long?)**, **Description (How?)**.
PDF version: [`Training3_Session_Plan.pdf`](Training3_Session_Plan.pdf)

> Topics are provisional until the official Training 3 learning objectives are confirmed.

**Learning objectives** (provisional, same as the quiz and the game). By the end of the training, participants are able to:

| # | Objective |
|---|---|
| LO1 | **Recognise** a security incident |
| LO2 | **Take the first steps:** stop and disconnect |
| LO3 | **Report** the incident quickly to the right person |
| LO4 | **Write down** what happened |
| LO5 | **Avoid** the common mistakes (paying, deleting, hiding) |

**Materials:** [slides](../slides/) (minutes 0–41 done), [web app](../quiz/) for the quiz and the game (QR code, <https://algoga22.github.io/Focus-Activity-Training3/>), paper [answer sheet](../02-learner-assessment/answer-sheet.pdf) as backup, Challenge 4 case sheet and Challenge 5 cheat sheet (to do).

**Balance:** about 35 of the 60 minutes participants are doing something themselves (quiz, votes, game, case), and theory never lasts more than 8 minutes in a row.

## Simple examples

**Writing a topic (start with an action verb):**
- ✅ "Recognise that something has gone wrong"
- ❌ "Incidents"
- ✅ "Apply the first steps after an incident"
- ❌ "Incident response theory"

**Writing a description (say *how*, not just *what*):**
- ✅ "Short explanation with 3 everyday examples, then participants say which ones are incidents"
- ❌ "Explain incidents"

## Evaluation checklist (100 pts)

| Criterion | Points |
|---|---|
| Each topic describes what participants will learn or do (action verb) | 20 |
| All points of the online training description are covered | 20 |
| No prerequisites beyond the Trainer Information Form | 5 |
| Description shows how each point is addressed (exercise, demo, discussion) | 20 |
| Varied, balanced methods alternating theory and practice | 15 |
| Realistic duration for each sequence | 15 |
| Total duration matches the official duration (1 hour) | 5 |

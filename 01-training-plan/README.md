# Challenge 1 – Training plan

Session skeleton: **Topic (What?)**, **Duration (How long?)**, **Description (How?)**.
PDF version: [`Training3_Session_Plan.pdf`](Training3_Session_Plan.pdf)

> Topics are provisional until the official Training 3 learning objectives are confirmed.

| Min | Topic (What?) | Duration | Description (How?) | Challenge |
|---|---|---|---|---|
| 0–5 | Welcome participants and introduce the session | 5' | Introductions, agenda and what they'll take home at the end | Slides |
| 5–10 | Assess what participants already know | 5' | Short quiz with 4–5 real-life situations ("What would you do if…?") | **Challenge 2** |
| 10–18 | Recognise that something has gone wrong | 8' | Explanation with everyday examples (hacked account, virus, email sent to the wrong person, lost laptop) and an analogy: it's like a fire, the sooner you spot it, the less damage it does | Slides |
| 18–26 | Apply the first steps | 8' | One easy-to-remember rule, e.g. **Stop, Disconnect, Report, Write down**. What to do and what NOT to do (don't delete anything, don't hide it, don't pay) | Slides |
| 26–41 | Play an incident response game | 15' | The game that brings together all the learning objectives | **Challenge 3** |
| 41–55 | Practise with a real NGO case and measure what participants have learned | 14' | Each participant first answers a realistic case alone on a short sheet (this shows what they have learned), then groups compare answers and the trainer runs the debrief (5' alone + 5' in groups + 4' debrief) | **Challenge 4** |
| 55–60 | Review key points and close | 5' | Hand out the cheat sheet, recap the key messages and collect feedback | **Challenge 5** |
| | **Total** | **60'** | | |

## Simple examples

**Writing a topic (start with an action verb):**
- ✅ "Recognise that something has gone wrong"
- ❌ "Incidents"
- ✅ "Apply the first steps after an incident"
- ❌ "Incident response theory"

**Writing a description (say *how*, not just *what*):**
- ✅ "Short explanation with 3 everyday examples, then participants say which ones are incidents"
- ❌ "Explain incidents"

## Evaluation checklist (100 pts)

| Criterion | Points |
|---|---|
| Each topic describes what participants will learn or do (action verb) | 20 |
| All points of the online training description are covered | 20 |
| No prerequisites beyond the Trainer Information Form | 5 |
| Description shows how each point is addressed (exercise, demo, discussion) | 20 |
| Varied, balanced methods alternating theory and practice | 15 |
| Realistic duration for each sequence | 15 |
| Total duration matches the official duration (1 hour) | 5 |
